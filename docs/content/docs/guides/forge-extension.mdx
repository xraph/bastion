---
title: Forge Extension
description: Integrate Bastion as a Forge extension with auto-configuration and DI container binding.
---

Bastion runs as a [Forge](https://github.com/xraph/forge) extension. It builds the proxy engine and its subsystems, wires in FARP discovery, mounts the admin API and provides `*bastion.Gateway` to the container. This guide covers setup in code and in YAML.

## Pick a constructor

There are two, and they build the same gateway:

| Constructor | Package | What you get |
|-------------|---------|--------------|
| `gateway.New(opts...)` | `github.com/xraph/bastion/gateway` | The full gateway. Admin-created routes live in memory and are gone after a restart. Pulls in no database driver |
| `extension.New(opts...)` | `github.com/xraph/bastion/extension` | The same gateway plus a store for admin-created routes and circuit breaker state, and the Forge dashboard contributor |

Don't register `bastion.New(...)` directly. It's the core gateway with nothing wired into it, so it registers no catch-all route and proxies nothing.

## Quick start

```go
package main

import (
    "log"

    "github.com/xraph/bastion"
    "github.com/xraph/bastion/gateway"
    "github.com/xraph/forge"
    "github.com/xraph/forge/extensions/discovery"
)

func main() {
    app := forge.NewApp(forge.AppConfig{
        Name:        "edge",
        HTTPAddress: ":8080",
        Extensions: []forge.Extension{
            discovery.NewExtension(discovery.WithBackend("memory")),
            gateway.New(
                bastion.WithBasePath("/api"),
                bastion.WithAdminToken("change-me"),
            ),
        },
    })

    if err := app.Run(); err != nil {
        log.Fatal(err)
    }
}
```

`app.RegisterExtension(gateway.New(...))` works too, as long as you call it before the app starts.

Once registered, the extension:

1. Loads configuration from YAML and applies your options over it.
2. Builds the route manager, circuit breakers, retry executor, traffic splitter, load balancer and proxy engine.
3. Provides the `*bastion.Gateway` instance to the DI container.
4. At start, picks up the `discovery` extension's service from the container, if there is one.
5. Registers the admin REST API, the WebSocket hub and the catch-all proxy route.

## Extension lifecycle

| Method | When called | What happens |
|--------|------------|--------------|
| `Register(app)` | App startup | Load config, build components, register with DI, set up the admin API |
| `Start(ctx)` | After all extensions registered | Wire discovery, load manual and persisted routes, start discovery, start the health monitor, register routes |
| `Health(ctx)` | Health check requests | Fails when no routes exist, otherwise asks the health monitor |
| `Stop(ctx)` | Graceful shutdown | Set draining mode, stop discovery, stop the health monitor |

The gateway lists the `discovery` extension as a dependency, but it doesn't need it. Without it, Bastion logs a warning at start and serves only the routes you configured or created through the admin API.

## YAML configuration

Bastion reads `extensions.bastion`, falling back to a top-level `bastion` key:

```yaml
# config.yaml
extensions:
  bastion:
    enabled: true
    base_path: "/api"

    routes:
      - path: /users/*
        targets:
          - url: http://user-service:8080
            weight: 1
        strip_prefix: true
        enabled: true

      - path: /orders/*
        targets:
          - url: http://order-service:8080
            weight: 1
        strip_prefix: true
        enabled: true

    discovery:
      enabled: true
      poll_interval: 30s
      auto_prefix: true
      prefix_template: "/{{.ServiceName}}"
      strip_prefix: true

    circuit_breaker:
      enabled: true
      failure_threshold: 5
      failure_window: 60s
      reset_timeout: 30s

    rate_limiting:
      enabled: false
      requests_per_sec: 1000
      burst: 100

    health_check:
      enabled: true
      interval: 10s
      timeout: 5s
      path: "/_/health"

    load_balancing:
      strategy: roundRobin

    dashboard:
      enabled: true
      base_path: /gateway
      title: "API Gateway"
      realtime: true
      admin_token: "change-me"

    openapi:
      enabled: true
      path: /openapi.json
      title: "My API Gateway"
```

`discovery.watch_mode` is accepted and defaults to `true`, but watching isn't implemented yet. Bastion logs a warning and polls every `poll_interval`.

### Config resolution order

1. `DefaultConfig()`.
2. The YAML file binds over it. Only the keys the file sets change, so a key the file leaves out keeps its default, and one it sets to `false` or `""` really is `false` or `""`.
3. Your `ConfigOption` functions run last. Each one sets only the fields it names, so options win over the file without wiping the rest of the block.

## Programmatic options

```go
import (
    "time"

    "github.com/xraph/bastion"
    "github.com/xraph/bastion/extension"
)

ext := extension.New(
    bastion.WithBasePath("/api"),
    bastion.WithDiscoveryEnabled(true),
    bastion.WithDiscoveryPollInterval(30 * time.Second),
    bastion.WithLoadBalancing(bastion.LoadBalancingConfig{
        Strategy: bastion.LBWeightedRoundRobin,
    }),
    bastion.WithCircuitBreaker(bastion.CircuitBreakerConfig{
        Enabled:          true,
        FailureThreshold: 5,
        ResetTimeout:     30 * time.Second,
        HalfOpenMax:      3,
    }),
    bastion.WithRateLimiting(bastion.RateLimitConfig{
        Enabled:        true,
        RequestsPerSec: 1000,
        Burst:          100,
    }),
    bastion.WithDashboardEnabled(true),
    bastion.WithOpenAPIEnabled(true),
)
```

`WithCircuitBreaker` and `WithRateLimiting` replace their whole block, so set every field you want. A `HalfOpenMax` of zero means the first successful probe closes the circuit; the default is 3.

### Key options

| Option | Description |
|--------|-------------|
| `WithBasePath(path)` | URL prefix for all proxied routes |
| `WithRoute(rc)` | Add a single manual route |
| `WithRoutes(routes)` | Set all manual routes |
| `WithServiceRoute(name, path, url, specURL)` | Add a route with an OpenAPI spec URL |
| `WithDiscoveryEnabled(bool)` | Enable or disable FARP discovery |
| `WithDiscoveryPollInterval(d)` | Set the discovery polling interval |
| `WithDiscoveryWatchMode(bool)` | Stored, but not implemented: discovery always polls |
| `WithLoadBalancing(cfg)` | Set the load balancing strategy |
| `WithCircuitBreaker(cfg)` | Configure circuit breakers |
| `WithRateLimiting(cfg)` | Configure global rate limiting |
| `WithHealthCheck(cfg)` | Configure upstream health checks |
| `WithAuth(cfg)` | Configure gateway authentication |
| `WithCaching(cfg)` | Configure response caching |
| `WithDashboardEnabled(bool)` | Enable or disable the admin API and WebSocket hub. The OpenAPI endpoints follow `OpenAPI.Enabled` instead |
| `WithAdminToken(token)` | Require `Authorization: Bearer <token>` on the admin API |
| `WithAdminMiddleware(mw...)` | Put your own auth in front of the admin API |
| `WithOpenAPI(cfg)` | Configure OpenAPI aggregation |
| `WithCORS(cfg)` | Configure gateway-level CORS |
| `WithTLS(cfg)` | Configure upstream TLS and mTLS |
| `WithConfig(cfg)` | Set the complete config struct |

## DI container integration

After registration, the `*bastion.Gateway` instance is in the DI container:

```go
gw, err := forge.Inject[*bastion.Gateway](app.Container())
if err != nil {
    log.Fatal("bastion not registered: ", err)
}

// Access gateway components
routes := gw.RouteManager().ListRoutes()
stats := gw.Snapshot()
hooks := gw.Hooks()
```

## Discovery

At start, the gateway looks up Forge's discovery service in the DI container. When it finds one, it wraps it in an adapter and hands it to the gateway with `SetDiscoveryService()`. No manual wiring is needed. If the discovery extension isn't registered, Bastion logs a warning and serves only manual and admin-created routes.

## Health check integration

The extension's `Health(ctx)` fails with "no routes configured" when the route table is empty, and otherwise returns the health monitor's verdict. Forge includes it in its aggregated health endpoint.

## Persistent store support

`extension.New` can keep admin-created routes and circuit breaker state in a database:

```go
ext := extension.New(
    bastion.WithDashboardEnabled(true),
).Configure(
    extension.WithGroveDatabase(""), // the default grove.DB
)
```

The store comes from `extension.WithStore(s)`, then the named `*grove.DB` from `WithGroveDatabase`, then the default `*grove.DB` in the container. The Grove driver picks the PostgreSQL, SQLite or MongoDB backend, and the store's migrations run at start unless you pass `extension.WithDisableMigrate()`. With none of those, the gateway runs in memory.

Only the in-memory store has tests today, so check the database backends against a real server before you rely on them.

## Dashboard integration

`extension.New` registers a contract contributor for the Forge dashboard. The UI lives in the `plugin-bastion` package of the [forge-dashboard](https://github.com/xraph/forge-dashboard) repo, which has overview, routes and upstreams pages. See [Admin Dashboard](/docs/api-reference/dashboard).

## Complete example

```go
package main

import (
    "log"

    "github.com/xraph/bastion"
    "github.com/xraph/bastion/extension"
    "github.com/xraph/forge"
    "github.com/xraph/forge/extensions/discovery"
)

func main() {
    app := forge.NewApp(forge.AppConfig{
        Name:        "edge",
        HTTPAddress: ":8080",
        Extensions: []forge.Extension{
            // Discovery for FARP service auto-discovery.
            discovery.NewExtension(discovery.WithBackend("memory")),

            // The Bastion API gateway.
            extension.New(
                bastion.WithBasePath("/api"),
                bastion.WithRoute(bastion.RouteConfig{
                    Path: "/users/*",
                    Targets: []bastion.TargetConfig{
                        {URL: "http://user-service:8080", Weight: 1},
                    },
                    StripPrefix: true,
                    Enabled:     true,
                }),
                bastion.WithDiscoveryEnabled(true),
                bastion.WithDashboardEnabled(true),
                bastion.WithOpenAPIEnabled(true),
                bastion.WithAdminToken("change-me"),
            ),
        },
    })

    if err := app.Run(); err != nil {
        log.Fatal(err)
    }
}
```

With the corresponding YAML config:

```yaml
# config.yaml
extensions:
  bastion:
    enabled: true
    base_path: "/api"
    routes:
      - path: /users/*
        targets:
          - url: http://user-service:8080
            weight: 1
        strip_prefix: true
        enabled: true
    discovery:
      enabled: true
    dashboard:
      enabled: true
      base_path: /gateway
    openapi:
      enabled: true
```
